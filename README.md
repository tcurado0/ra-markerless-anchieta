## Sobre o projeto

Aplicativo web de Realidade Aumentada markerless que mostra, pela câmera do celular, a localização dos prédios do campus. Cada ponto aparece com um marcador 3D e o nome do prédio logo acima.

Pontos mapeados: Prédio 1, Prédio 2, Prédio 3, Prédio 4 e Anfiteatro (todos com no mínimo 50 m de distância entre si).

## Acesso

- **App:** https://tcurado0.github.io/ra-markerless-anchieta/
- No computador, use o botão **Modo simulação**.

## Como usar

1. Abra o link no celular (Chrome no Android ou Safari no iPhone).
2. Toque em **Iniciar Realidade Aumentada**.
3. Permita o acesso à câmera, à localização e aos sensores de movimento.
4. Aponte o celular ao redor para ver os prédios.

## Tecnologias

HTML, CSS, JavaScript, WebGL, Geolocation API, DeviceOrientation API e GitHub Pages.
